## How to Run

1. Install the Java Development Kit (JDK).
2. Open the project folder in VS Code.
3. Open the terminal.
4. Compile the Java file:

   ```bash
   javac src/Main.java
   ```

5. Run the program:

   ```bash
   java -cp src Main
   ```
